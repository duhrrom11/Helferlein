Verschlüsselte Nachlassübergabe

Eine freiwillige, sofortige und endgültige Dateiübergabe. Sie ist unabhängig von Erbeneinladungen und deren Widerruf. Wer das Paket und den passenden privaten Schlüssel besitzt, kann die Daten dauerhaft lesen. Für eine spätere, widerrufbare Freigabe ist diese Funktion nicht geeignet.

1. Erbe: Schlüsselpaar erstellen

Der private Schlüssel bleibt beim Erben. Speichere ihn sicher und teile ausschließlich den öffentlichen Schlüssel.

2. Besitzer: Nachlass verschlüsselt übergeben

Öffne diese Seite auf dem Gerät mit deinem bestehenden lokalen Helferlein-Tresor. Wähle den öffentlichen Schlüssel des Erben. Die Verschlüsselung erfolgt ausschließlich in deinem Browser.

3. Erbe: Nachlass lokal öffnen

Es werden keine Schlüssel, Passwörter oder Nachlassinhalte an einen Server gesendet. Diese Seite benötigt einen aktuellen Browser mit Web Crypto. Geheime Dateien niemals öffentlich teilen.
